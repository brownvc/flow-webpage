Updating

Toe the cutting edge!

The installer again?

Yes, indeed! To update Flow, you can actually use the installer script! It will go ahead and download the latest version, and replace the existing version if it exists. So if you have it still, just run it again! If you don't have it then you can download it again here.

⬇ Download the Installer

⚠️
HOLD IT!! Updating/reinstalling will replace your current session on previous versions of the installation script. If you want to make sure this doesn't happen, it's safest to redownload a fresh installation script and use that instead!
