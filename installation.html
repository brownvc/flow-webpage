Installation

Let's get started!

(Windows) Download the Executable

If you're on Windows, you can download a zip folder with the .exe here, and then just run it from that directory!

⬇ Download the Windows Executable

(Mac) Download the Installer

To install Flow, if you're on Mac, we've provided an installer script to run in the terminal. You can download it here!

⬇ Download the Installer

How to Install

If you're unfamiliar with how shell scripts work, here's some further instruction!

1

Open the terminal

Open the terminal - if this is unfamiliar to you, press Command + SPACEBAR, type "Terminal", and hit enter

2

Navigate to the Downloads folder

Type in "cd ~/Downloads" in the terminal, and hit enter

3

Add run permissions to the install script

Type in "chmod +x install.sh" in the terminal, and hit enter

4

Run the install.sh script

Type in "./install.sh" in the terminal, and hit enter


Once you've followed these steps to run the script, you'll be promted by the script for the rest of the installation!

⚠️
Heads up: Some dependencies may require a system restart to take effect. When convenient, make sure to restart your device if Flow has some issues the first time you open it!
