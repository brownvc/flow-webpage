What is Flow?

Flow is a visual simulation tool to simulate flow-firing on complex structures. Currently only the tetrahedral-octohedral honeycomb is supported, but more on the way!

How It Works

Flow allows you do to three core utilities:

1

Configure a simulation

Configure a structure with whatever parameters you want! Not to worry - progress will be saved when you close.

2

Simulate a configuration

Step through a simulation, or let it run as fast as possible! Flow will efficiently calculate what you need.

3

Visualize and Analyze

Flow features plenty of different ways of viewing the simulation to spark inspiration! Explore the way to visualize the best for you.
